# Guía de inicio en Inteligencia Artificial

Página de práctica en HTML con una selección de videos y recursos en español para entender qué es la inteligencia artificial, el machine learning y las redes neuronales.

🔗 **Ver la página:** https://eddie-dev-ca.github.io/guia-ia/

## Qué practiqué en este proyecto

### Estructura del documento
- `<!DOCTYPE html>` y `<html lang="es">` para declarar el tipo de documento y el idioma
- `<meta charset="UTF-8">` y `<meta name="viewport">` para la codificación y la adaptación a móviles
- `<title>` y `<meta name="description">` para el título y la descripción en buscadores

### Open Graph (vista previa al compartir)
- `og:title`, `og:type`, `og:url`, `og:description`
- `og:image` con ruta absoluta y `og:image:alt` para accesibilidad

### HTML semántico
- `<main>`, `<section>` y `<footer>` para organizar el contenido
- Jerarquía de títulos con `<h1>` y `<h2>`
- Entidades HTML, como `&copy;`

### Contenido multimedia y enlaces
- `<iframe>` con videos de YouTube (`/embed/`), con `title` descriptivo y `allowfullscreen`
- `<img>` con `alt` descriptivo y `width` y `height` para reservar el espacio
- Lista de enlaces con `<ul>`, `<li>` y `<a>`, usando `target="_blank"` y `rel="noopener noreferrer"`

### Calidad
- Código validado con el [validador del W3C](https://validator.w3.org/) sin errores ni advertencias
- Publicado con GitHub Pages
